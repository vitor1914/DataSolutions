# DataSolutions — Simulação Profissional em Dados

## Sobre o projeto

Ambiente de simulação profissional que reproduz o cotidiano de um profissional de Análise de Dados e Engenharia de Dados.

A proposta é desenvolver experiência prática por meio de demandas empresariais, projetos, manutenção de sistemas, análise de dados e entregas técnicas.

## Organização

- `demandas/`: registro das solicitações recebidas.
- `projetos/`: projetos desenvolvidos durante a simulação.
- `entregas/`: registros das entregas concluídas.
- `acompanhamento/`: histórico de atividades e evolução profissional.

## Funções

- Profissional: execução das demandas e desenvolvimento das soluções.
- Gestor técnico: ChatGPT, responsável por apresentar demandas, orientar, revisar e avaliar entregas.

## Tecnologias

- Python
- SQL
- Pandas
- NumPy
- PostgreSQL
- Power BI
- Excel
- APIs
- Docker
- Git e GitHub

As ferramentas serão utilizadas conforme as necessidades das demandas.

## Fluxo de trabalho

1. Receber a demanda.
2. Analisar o problema.
3. Planejar a solução.
4. Desenvolver.
5. Executar testes.
6. Realizar correções.
7. Documentar.
8. Entregar.
9. Registrar o commit.

## Avaliação

As entregas serão avaliadas considerando qualidade do código, organização, lógica, testes, documentação e cumprimento dos requisitos.

## Evolução

A complexidade das atividades aumentará progressivamente, respeitando a evolução técnica demonstrada.

## Objetivo final

Desenvolver experiência prática, fortalecer o portfólio profissional e preparar para oportunidades no mercado de Análise e Engenharia de Dados.
